Overview

Every game server this panel manages, at a glance.

Add a game

Pick a game and give the server a name. You can add the same game more than once, for example one server per group of friends. Game files are downloaded when you press Install.

Checking…
Installing downloads the game server files and verifies them. You can leave this page; it keeps going.

Unsaved changes

Changes apply the next time the server starts. “Save & restart” does both.

Startup

Game files

Check for updates downloads and verifies the latest game files. Clean & reinstall deletes the game files and downloads them again; your config is kept.

Server pack

Upload a modpack's server zip to install it or replace the current one. Mods and configs are replaced; the world, ops, whitelist and ban lists are kept. Stop the server first.

Remove from panel

Stops the server and removes it from the sidebar. Downloaded game files and config stay on disk.
